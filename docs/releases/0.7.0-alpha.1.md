- **Release pipeline (M7):** releases now build from an intentional version tag,
  run every frontend, server and Rust test, verify the installer and checksum,
  attach the exact verified artifact to a draft GitHub Release and only then
  publish it, so a tagged alpha goes public without a manual step.
- **Signing-ready:** when a code-signing certificate is configured, the app
  executable is signed before bundling and the installer is signed afterwards;
  the checksum is then computed from the signed installer. Without a certificate
  the build is reported as unsigned, never as signed.
- **Startup fix:** the main window is now revealed through the OS window, so a
  launch cannot leave a running process with no visible window. Startup
  diagnostics are written next to the database.
- **M6 reliability work remains included:** reconnect recovery, voice/stream/
  control cleanup, revoked-session detection and the 35-minute soak.
- **Local mode works out of the box:** the installer now bundles the signaling
  server as a Windows sidecar. It starts with Meldrift on a loopback port,
  waits for a real health check, restarts after a crash and stops with the app.
  Remote server mode remains available for cross-PC play; see
  `docs/DEPLOYMENT.md`.
- **Neutral profile defaults:** onboarding and account fields use neutral
  placeholders (`Display name`, `username`) instead of a personal name. Existing
  profiles keep their saved names, and no name is taken from the Windows
  account.
